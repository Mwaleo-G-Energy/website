# Launch catalogue

Create these categories in Mwaleo’s Wix Stores dashboard. Use the same slugs so existing storefront links pick up the Wix listings.

| Category | Wix slug |
|---|---|
| Off-grid inverters | `off-grid-inverters` |
| Lithium batteries | `lithium-batteries` |
| Solar kits | `solar-kits` |

Use **Felicity Solar** as the product brand. Keep demo products hidden before publishing the catalogue. Add the models Mwaleo confirms it stocks, using its VAT-inclusive KES prices. Publish each kit as a single product once Mwaleo confirms its components and price.

## Source example

The first source checked was the Felicity Solar IVEM6048-II. It is a single-phase, 6 kW off-grid inverter with a nominal 48 V battery input and a maximum PV input of 7.5 kW. Its render appears on the homepage as an example. Stock, local price and warranty terms need Mwaleo’s confirmation before the model is published as a product.

Use Felicity’s [IVEM6048-II product page](https://felicitysolar.us/product/ivem6048-ii/) and [English user guide](https://felicitysolar.us/download/ivem6048-ii-user-guide-en/) to cross-check this model. Use the [off-grid catalogue](https://felicitysolar.us/all-off-grid-inverter) to find the official page and downloads for each confirmed model.
